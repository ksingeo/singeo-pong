# Singeo Pong: Neon Nights

A Pong game set in a neon beach city at sunset, in one HTML file. Open `index.html` in any web browser to play.

- **Mouse**, **W / S**, or **Arrow Up / Arrow Down**: move your paddle
- **Easy / Normal / Hard** buttons, or keys **1 / 2 / 3**: choose a difficulty (starts a new game)
- **P** or the **Pause** button: pause and resume
- First to 5 points wins. Press **Space** to play again.
